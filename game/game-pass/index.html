Is Minecraft Dungeons 2 on Xbox Game Pass?

Published September 24, 2026 · Updated September 25, 2026

Launch-week info, last checked Sep 25, 2026. We update this page as patches and new data land.

Short answer

Yes. Minecraft Dungeons 2 is confirmed day one on Xbox Game Pass Ultimate and PC Game Pass by Xbox Wire and the Xbox Store. It also supports Xbox Play Anywhere. Online play on console still needs its own Xbox Game Pass Essential, Premium or Ultimate subscription.

Minecraft Dungeons II releases September 29, 2026 on Windows, Xbox Series X|S, PlayStation 5, Nintendo Switch and Nintendo Switch 2. On Xbox and PC, subscribers get another way in beyond a direct purchase, and there’s one console-specific catch worth knowing before launch day.

Is Minecraft Dungeons 2 on Game Pass day one?

Yes. Xbox Wire’s own September 2026 Game Pass wave announcement lists the game arriving September 29, the same day as its retail release, on Xbox Game Pass Ultimate and PC Game Pass. The Xbox Store’s game listing confirms the same two tiers. Subscribers on either plan can play the full game the moment it releases, with no separate purchase needed.

Which Game Pass tiers include it?

Two, confirmed directly: Xbox Game Pass Ultimate and PC Game Pass. Xbox’s own store listing for the game names these specifically; it does not list the game under any lower-priced Game Pass tier.

Game Pass tier Included at launch
Xbox Game Pass Ultimate Yes, confirmed by Xbox Wire and the Xbox Store
PC Game Pass Yes, confirmed by Xbox Wire and the Xbox Store
Lower Xbox Game Pass tiers (Essential, Premium) Not listed as including the game itself

Don’t confuse this with the separate online-play requirement below. Essential and Premium are named on Xbox’s store page in a different context: as tiers that unlock online multiplayer on console, not as tiers that include the game in your library.

Do I still need to pay anything if I have Game Pass Ultimate?

Not to play the base game solo. Game Pass Ultimate includes full access to the game on both console and PC at no extra cost. Where a separate cost can come in is Deluxe Edition content: the Xbox Store’s Deluxe listing sells its DLC, skins, cape and pet bundle separately from the base game Game Pass grants you, so Game Pass gets you the full base campaign, not the Deluxe cosmetics and DLC on top of it.

Do I need a separate subscription to play online through Game Pass?

On console, yes. The Xbox Store’s own Deluxe Edition page states: “Online multiplayer on console requires XBOX Game Pass Essential, Premium, or Ultimate (subscriptions sold separately).” If you’re already on Game Pass Ultimate, that requirement is already satisfied, since Ultimate is one of the three qualifying tiers. If you access the game some other way on console, you’d still need one of those three tiers active to play online. On PC, Xbox’s store pages don’t list an equivalent separate online-play subscription requirement.

What is Xbox Play Anywhere, and does it matter if I use Game Pass?

Xbox Play Anywhere means a single purchase of the game unlocks it on both an Xbox console and Windows PC under the same account, confirmed on both the Xbox Store’s Deluxe and standard listings. If you’re playing through Game Pass rather than buying the game outright, Play Anywhere isn’t the relevant benefit for you, since Game Pass already grants access on both console and PC as part of the subscription. Play Anywhere matters specifically if you buy the game instead of subscribing, so you’re not forced to pick one platform.

Is Minecraft Dungeons 2 worth playing through Game Pass instead of buying it?

That depends on whether you already subscribe to Game Pass Ultimate or PC Game Pass for other games. If you do, playing the game costs nothing extra on day one. If you don’t already subscribe, compare the subscription price against the $29.99 Standard Edition price on the editions page to see which works out cheaper for how long you expect to play.

If you’d rather own it outright, see our Standard vs. Deluxe breakdown, or check whether Minecraft Dungeons 2 is worth buying at all before committing either way. On PC, confirm your machine meets the system requirements before launch, regardless of whether you buy or subscribe.

Quick FAQ

Does Xbox Game Pass Core include Minecraft Dungeons 2? Xbox’s store listing names only Ultimate and PC Game Pass as including the game itself. Core (now grouped under Essential in Xbox’s tier naming) is named separately as an online-play requirement, not as a tier that includes this title.

Can I play Minecraft Dungeons 2 offline through Game Pass? Mojang and Xbox haven’t published offline-play details specific to Game Pass access. The online-subscription requirement described above applies to online multiplayer on console, not necessarily to solo offline play; we’ll confirm this distinction once it’s spelled out or testable at launch.

Does PC Game Pass also require a separate online subscription? Xbox’s store pages don’t list a PC-specific online-play subscription requirement the way they do for console. Treat PC as not gated behind that extra tier based on what’s published so far.

If I cancel Game Pass after launch, do I lose the game? Standard Game Pass behavior across Xbox’s library is that access ends when your subscription lapses unless you separately own the game. Xbox hasn’t published a Minecraft Dungeons II-specific exception to that rule.

Not confirmed yet

Whether Xbox Game Pass Essential or Premium (the tiers below Ultimate) will ever add the game to their game libraries, rather than just satisfying the online-play requirement, hasn’t been announced. Xbox also hasn’t detailed whether progress carries over if you play through Game Pass first and later buy the game outright. If you’re on a lower tier than Ultimate, check your library directly on launch day rather than assuming access.
