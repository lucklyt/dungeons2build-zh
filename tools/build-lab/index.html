          How to plan a build

          1. Tap a slot. A picker opens with every matching item from the gear database.
          2. Search or filter. Type a name or an effect such as "freeze", or filter by rarity or category. Arrow keys and Enter work too.
          3. Add enchantments. Each weapon and armor piece has its own enchantment button. Only enchantments that fit that piece are listed.
          4. Read the role. The panel adds up the tags on your gear and names what the build does best, with a bar for each role.
          5. Share it. Press Copy link. The address holds your whole loadout, so opening it restores every slot.

          配装实验室 questions

          How many slots does a Minecraft Dungeons 2 build have?

          A full build has twelve slots: one melee weapon, one ranged weapon, four armor pieces, three artifacts and three talismans. 配装实验室 also gives every weapon and armor piece one enchantment button, because the number of enchantment sockets per item has not been documented yet.

          How does 配装实验室 work out a build’s role?

          Each item carries tags taken from its listed effect, such as crowd control, area damage, support or tank. 配装实验室 counts the tags across your loadout and shows the biggest share as the role. Gear without a documented effect adds nothing, so a thin readout usually means missing data, not a weak build.

          Can I save or share a build?

          Yes. The address bar updates as you pick gear, so the link is the save file. Press Copy link and send it, or bookmark the page. Nothing is stored on our servers, and Reset clears every slot.

          Does 配装实验室 include set bonuses and enchantment levels?

          Not yet. It counts how many armor pieces you take from one set, but set bonuses are not documented. Enchantments show levels I to III, the cap the game uses, and per-level values are not published, so 配装实验室 does not add them up.
